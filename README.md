# 鱼播（Yubo）3.4.0

相对上一正式版 3.3.2 的发布更新见 [CHANGELOG.md](CHANGELOG.md)。发布前内部迭代记录另存于 tests/development-notes.md，不随安装包分发。

鱼播是一款 Chrome Manifest V3 扩展，用于查看哔哩哔哩、斗鱼和虎牙的关注主播是否开播，并按需发送桌面提醒。项目是对原版 [kaibola](https://github.com/daochouwangu/kaibola) 的二次开发版本；当前版本不包含 Twitch。

## 功能

- **关注列表**：集中查看三个平台的关注主播、开播状态、分类和房间号；支持手动刷新、定时刷新和平台筛选。
- **搜索与筛选**：按主播名称、别名、拼音/首字母、分类或房间号搜索；无匹配结果时可将关键词直接带到斗鱼、虎牙或 B 站搜索；可筛选全部、正在直播、收藏和收藏分组。
- **收藏与管理**：收藏主播、创建收藏分组、调整收藏顺序、为主播添加多个别名。别名会显示在主页卡片上并参与搜索。
- **活动临时关注**：在设置里添加和管理多个活动，各活动以自己的名称显示在分组栏；支持改名、预览勾选、更新该活动名单、删除、搜索、平台筛选和只看正在直播。卡片沿用原列表样式，仅去掉收藏爱心；不加入正式关注、收藏、通知或历史。
- **直播卡片**：用户名右侧以小号、浅色、斜体显示直播间标题，长标题缓慢往返滚动，悬停时暂停，短标题保持静止。普通列表和封面卡片共用；没有标题时不占位。不同平台使用各自风格的开播图标；开播主播悬停时可查看静态直播封面。所有列表标签均支持封面模式（按钮或 `V` 切换），开启后只显示当前标签中确认正在直播的主播；切换标签保留模式，退出恢复普通列表。默认关闭，不是录屏或视频流。
- **开播提醒**：选择提醒全部关注主播、仅提醒收藏主播或关闭提醒；支持检查间隔、合并通知、全局暂停、免打扰时段和分组通知开关。单主播可沿用全局设置，也可单独开启或关闭提醒，单人设置优先于全局默认。
- **快捷键**：关注列表支持快速搜索、刷新、切换列表，并提供独立的快捷键说明页面。
- **平台诊断**：显示已启用平台的读取/授权状态；登录失效时提供重新授权入口。取消启用的平台不会继续检查或提示授权。
- **最近开播记录**：在本机查看最多 100 条检测记录，可查看开始时间和直播时长，也可清空记录。
- **备份与迁移**：导出或导入设置 JSON；也可手动通过 WebDAV 上传备份或从 WebDAV 恢复。WebDAV 不是自动实时同步。

主页列表当前大致按“收藏优先、已开播优先”排列：收藏项按收藏顺序，同一开播状态内排序；未收藏项按开播状态分组后，再按主播名称排序。

## 安装和使用

1. 使用 Chrome 登录需要读取关注列表的平台（哔哩哔哩、斗鱼、虎牙）。
2. 打开 `chrome://extensions`，启用右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择**包含本 README 和 `manifest.json` 的项目根目录**。
4. 点击鱼播扩展图标即可打开关注列表；在页面导航中进入“设置”可配置提醒、主播管理、平台诊断和备份。

本项目为纯前端扩展目录，目前无需安装依赖或执行构建命令。使用 WebDAV 时，扩展会另行请求访问所填服务器的权限；服务器地址和目录由用户自行配置。

## 活动临时关注

管理入口位于“设置 → 临时活动”。添加后，各活动的名称显示在关注列表顶部“全部 / 正在直播 / 收藏 / 各分组”的同一排，可点击或用左右方向键切换。

1. 点击“添加活动”，填写名称，选择“活动页链接”并粘贴活动入口，每个活动可解析最多 5 页；也可选择“直播间链接列表”，粘贴混合的斗鱼、虎牙和 B 站直播间地址，或读取本机 txt / JSON / HTML 链接文件。
2. 点击“解析并预览”，核对识别结果、勾选需要的房间，再保存为独立活动。最多保存 20 个活动，每个活动最多 300 位主播；解析失败或取消不会清空原数据。
3. 导入后后台读取主播名称、头像和直播状态；在分组栏选择活动查看，直播中优先展示，支持搜索、平台筛选和“只看正在直播”。页面顶部“刷新”和设置中的“刷新状态”只检测现有名单的状态，不增删参与主播。
4. 活动增减参与主播时，在设置中点击该活动的“更新名单”：重新读取已保存的活动来源，预览新增/移除人数，确认后只更新这一个活动。如果要换来源或调整手动链接，使用“编辑来源 / 名单”。名称可直接修改后点击“保存名称”。
5. 活动结束后删除该活动即可，不影响其他活动或正式关注。关闭再打开浏览器不会自动删除活动。

### 识别准确性与支持边界

活动页解析仅支持斗鱼平台活动，且有一定几率识别失败。请核对预览；手动直播间链接列表仍支持斗鱼、虎牙和 B 站。

- 对带有明确官方活动配置的斗鱼页面，优先读取配置中的主播房间号，不从整页推荐或导航链接猜测。2026-10-21 用实际网页快照检查 `https://www.douyu.com/91124` 和 `https://www.douyu.com/1369397`，提取的 86 个、32 个房间号分别与各自配置逐项一致；活动内容后续可能变化，人数不是固定值。
- 没有已支持的活动配置时，从页面中可读取的直播间链接提取，并提示可能不完整。虎牙、B 站活动页，以及其他斗鱼活动模板，不保证动态脚本、iframe 或需要登录验证后的内容都能自动识别；此时可复制活动里的直播间链接，以“直播间链接列表”方式导入。
- 预览会显示“活动官方配置”“页面链接（需核对）”或“直播间链接列表”，不宣称所有页面都能百分百识别。自动去除重复链接，一次最多导入 300 个直播间。
- 三个平台的单房间状态来自公开只读信息，不依赖是否关注主播。视频轮播不算正在直播；网络或接口异常显示“状态未知”，不冒充未开播。B 站资料接口不可用时名称可能暂以平台和房间号代替。

### 保存、刷新与权限

- 多活动数据单独保存在 `chrome.storage.local` 的 `yubo_temporary_activities`，不写 Chrome 同步存储，不导出到设置备份或 WebDAV，不混入正式关注、收藏、提醒与直播记录。旧的 `yubo_temporary_list` 自动迁移为名叫“临时活动”的一个活动，原键仅保留为迁移备份，不继续读取；删除后不会从备份自动恢复。
- 按原有检查间隔在后台刷新，页面也可手动刷新；合并同一活动的并发请求，自动刷新复用 30 秒内的状态结果。状态检测不会自动增删活动主播；名单更新与删除后，旧检测结果不能恢复旧名单，改名也不会被检测结果覆盖。
- 新增的站点权限仅为斗鱼官方活动配置域名 `https://butterfly.douyucdn.cn/*`；不添加 `scripting`、Cookie 或本机程序权限，不执行活动页的脚本，不自动打开平台网页。升级后请在扩展管理页重新加载鱼播，使新权限及后台生效。
- 此功能在 `yubo-3-2` 目录的 3.x 源码上开发，当前版本为 3.4.0；已封存的 4.x 没有修改。分组栏独占一行，过多时横向滚动；搜索框和平台筛选另起一行，不受分组数量影响。设置里的活动管理采用紧凑列表，来源和检测时间点击“详情”展开；列表最高 360 像素，更多活动在内部滚动。

### 开发验证

`node --test tests/room-data.test.cjs tests/temporary-list.test.cjs` 还会执行真实后台轮询代码，检查三个平台标题持久化、字段缺失时的缓存保留、新标题替换，以及虎牙登录失效和异常返回时的数据保护。接口响应在此测试中使用固定样本，不等同于登录态实测。

`pwsh -File tests/huya-live-check.ps1` 实时核对虎牙公开房间的 `introduction` 和官网“我的关注”脚本的 `sLiveDesc`。该脚本不读取登录凭据，未登录关注接口返回 1401；因此该脚本本身不代表登录态验证。2026-10-21 已通过用户提供的登录响应截图确认当前 `subscribeList` 标题字段为 `intro`，脱敏结构样本保存在 `tests/fixtures/huya-subscribe-record.json`，页面与后台回归均使用该字段。

`node --test tests/temporary-list.test.cjs` 检查解析、安全边界、去重、状态未知、多活动隔离、旧数据迁移，以及改名/名单更新/删除与刷新竞态。

`pwsh -File tests/temporary-live-check.ps1` 只读获取上述两个活动页及三个平台的公开房间信息，再将实际返回内容送入同一解析器验证；无需读取浏览器 Cookie。可通过 `-NodePath` 指定 Node 可执行文件。

`node tests/temporary-ui-check.cjs` 使用 Playwright 和独立的本地测试浏览器验证设置中新增多个活动、改名、名单增删、单独删除、分组切换、卡片样式和原列表隔离。可通过 `YUBO_TEST_BROWSER` 指定浏览器路径；该测试阻止外部网络，不使用现有浏览器配置。测试截图写入 `tests/artifacts/`。

## 项目结构

```text
├── manifest.json                  # Chrome 扩展权限、入口和基本信息
├── icon*.png / icon.svg           # 扩展图标
├── static/
│   └── background/
│       └── yubo-worker.js          # 后台定时检查、状态变化、通知和开播记录
└── tabs/
    ├── launch.html / launch.js     # 扩展弹出入口，打开关注列表
    ├── index.html                  # 关注列表页面
    ├── live-list.js / *.css        # 平台数据、筛选搜索、主播卡片和样式
    ├── history.html / history.js   # 最近开播记录
    └── settings.html / settings.js # 提醒、主播管理、诊断、备份与 WebDAV
```

## 数据与隐私

- 扩展通过浏览器中已有的平台登录会话读取关注数据；不要求用户把平台密码填入扩展。
- 关注列表缓存、分组、别名、提醒设置和开播记录保存在 Chrome 扩展存储中；部分设置使用 Chrome 同步存储，其余为本机存储。
- 导出的备份不包含平台 Cookie 或登录令牌。WebDAV 用户名、密码和地址配置仅保存在扩展本机存储中；WebDAV 操作由用户手动触发。
- 开播记录的开始时间是扩展轮询时首次检测到开播的时间，不一定等于平台实际开播时间。未登录、网络异常或平台接口变化可能导致列表数据暂时不可用或沿用缓存。

## 开发说明

扩展采用 Manifest V3：`static/background/yubo-worker.js` 由 Chrome Service Worker 运行，负责按设置间隔轮询平台、比较开播状态变化、创建通知并维护本机历史；`tabs/` 下的页面负责列表、设置和记录展示。平台网页接口由各平台维护，可能发生变化。

修改后可在 `chrome://extensions` 中点击扩展的刷新按钮，再重新打开页面验证。
