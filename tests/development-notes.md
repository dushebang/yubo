## 3.4.1 修复记录：临时活动随备份迁移

- 根据用户截图补充“新设置页 + 旧后台”兼容回归：活动导出改为页面直接只读存储，不再调用旧后台不存在的 export-backup 指令；恢复使用旧后台也认识的 read 操作先检查能力，能力不足时不写入任何设置，提供用户主动触发的后台重载入口。

- WebDAV 上传后通过实际 GET 读回核对本次备份时间和活动定义，上传与恢复提示均显示活动/主播条目数；恢复后再读取本机存储确认活动名单。旧备份不含活动、读回不一致和本机写入不一致会分别提示。
- 跨独立浏览器环境通过本机临时 HTTP 服务的实际 PUT/GET 测试；用户真实 WebDAV 备份尚需以操作后的计数核对，不能仅凭“同一个源码目录”认定运行中的页面与后台已加载新逻辑。

- 设置 JSON 与 WebDAV 共用的备份纳入活动名称、来源和选定主播名单，可导出到其他浏览器；不迁移登录凭据和实时开播状态。
- 旧备份缺少活动字段时保留现有活动，新备份明确为空时清空；无效活动在设置写入前拦截。
- 恢复通过后台串行写入，重新生成活动标识与修订号，防止在途轮询覆盖恢复名单；经用户确认将源码版本更新为 3.4.1，不改已发布 3.4.0 Release 或安装包。

## 3.3.0 · 开发过程汇总

### 新功能

- 支持哔哩哔哩、斗鱼、虎牙三个平台的关注主播状态检查与开播提醒；移除 Twitch 平台功能。
- 增加平台诊断：查看平台读取状态、主播数量、最近检查时间和授权失效原因；可分别启用平台，并从列表或诊断页重新授权。
- 增加主播级提醒覆盖：未单独设置时沿用全局默认；可为单个主播单独开启或关闭，覆盖全局默认和分组提醒规则。
- 增加收藏分组管理、分组提醒开关、主播别名管理和主播列表拖动排序。
- 增加主播最近开播记录页面，记录由扩展检测到的开播状态变化。
- 增加封面模式：在“正在直播”列表中切换为封面卡片，默认仍使用原列表；卡片展示封面、头像、用户名、直播标题和收藏按钮。
- 增加快捷键说明页面及主页快捷键：`/` 聚焦搜索、`Esc` 清空搜索、`R` 刷新、`1`/`2`/`3` 切换列表、`?` 打开说明。
- 增加设置 JSON 导入导出和手动 WebDAV 上传/恢复；WebDAV 支持单独填写目录，目录留空时使用服务器映射的根路径。

### 界面与交互调整

- 为三个平台设计风格统一的平台图标，并使用各平台主题色标记开播状态；收藏标记由星形改为主题绿色爱心。

- 将收藏分组新增入口改为紧凑的“+”按钮，并使用弹窗管理分组。
- 将别名操作反馈改为自动消失的小提示，避免提示文字长期占据页面。
- 调整免打扰时间与提醒选项的布局；弹窗打开后自动聚焦对应输入框。
- 将“直播记录”和“快捷键”纳入统一导航，并让导航栏保持悬浮。

### 问题修复与可靠性改进

- 修复主播管理列表拖动排序不起作用的问题。
- 修复搜索框失焦后按 `Esc` 无法清空搜索的问题；输入控件和输入法组合输入期间避免误触快捷键。

- 调整直播封面预览的位置，尽量避免预览框被页面边缘裁切。
