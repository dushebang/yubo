# 开发过程记录（不随正式安装包分发）

## 3.4.1 待发布修复：临时活动随备份迁移

- 根据用户截图补充“新设置页 + 旧后台”兼容回归：活动导出改为页面直接只读存储，不再调用旧后台不存在的 export-backup 指令；恢复使用旧后台也认识的 read 操作先检查能力，能力不足时不写入任何设置，提供用户主动触发的后台重载入口。

- WebDAV 上传后通过实际 GET 读回核对本次备份时间和活动定义，上传与恢复提示均显示活动/主播条目数；恢复后再读取本机存储确认活动名单。旧备份不含活动、读回不一致和本机写入不一致会分别提示。
- 跨独立浏览器环境通过本机临时 HTTP 服务的实际 PUT/GET 测试；用户真实 WebDAV 备份尚需以操作后的计数核对，不能仅凭“同一个源码目录”认定运行中的页面与后台已加载新逻辑。

- 设置 JSON 与 WebDAV 共用的备份纳入活动名称、来源和选定主播名单，可导出到其他浏览器；不迁移登录凭据和实时开播状态。
- 旧备份缺少活动字段时保留现有活动，新备份明确为空时清空；无效活动在设置写入前拦截。
- 恢复通过后台串行写入，重新生成活动标识与修订号，防止在途轮询覆盖恢复名单；经用户确认将源码版本更新为 3.4.1，不改已发布 3.4.0 Release 或安装包。

> 以下保留发布前的内部迭代记录，不代表曾发布这些中间版本。正式版本与发布日志以 manifest.json、CHANGELOG.md 为准。

## 发布前第 8 次开发迭代 · 2026-10-21

- 根据用户提供的真实登录响应截图确认：虎牙 subscribeList 标题字段为 intro（截图值“回来开工”），修复此前漏读该字段的问题。页面与后台共用同一映射，兼容其他虎牙数据格式的 introduction、sLiveDesc 等字段。
- 后台现在保存三个平台的标题；本次缺少标题时保留同房间的上次标题，并在完整标题提示中注明缓存来源，新标题返回后自动替换。
- 虎牙返回未登录状态 1401 或名单格式异常时保留原列表，不再作为空列表成功写回。
- 使用已确认字段的脱敏结构样本验证页面标题、后台轮询保存、字段缺失时保留缓存及新标题替换；登录失效和异常格式继续保留原列表。自动化不读取用户登录凭据。

## 发布前第 7 次开发迭代 · 2026-10-21

- 修复直播间标题中的 HTML 实体被原样显示：正确处理空格、引号、与号、数字编码符号和表情，以及重复转义的实体。
- 普通格子、封面卡片及悬停完整标题统一修复；仍按纯文本安全显示，不执行标题中的 HTML 或脚本。
- 直播间标题按文字基线与用户名底部对齐，不再垂直居中。

## 发布前第 6 次开发迭代 · 2026-10-21

- 所有列表及封面卡片共用用户名右侧的直播间标题：小号、浅色、斜体，不另占一行，也不增加普通格子高度。
- 长标题超出可用宽度时缓慢往返滚动，短标题静止；悬停或键盘聚焦时暂停。窗口缩放后自动重新判断，尊重系统减少动态效果设置。
- 没有标题时不显示空白占位，保留原有分类、房间号、别名和收藏行为。

## 发布前第 5 次开发迭代 · 2026-10-21

- 新增 V 快捷键切换封面模式，按钮提示与快捷键说明同步更新；输入框、输入法组合输入及带修饰键时不触发。
- 活动封面卡片不显示收藏爱心，退出封面模式恢复原列表筛选。

## 发布前第 4 次开发迭代 · 2026-10-21

## 发布前第 2 次开发迭代 · 2026-10-21

### 临时活动管理调整

- 将活动新增、改名、编辑来源、更新名单、刷新状态和删除入口统一放到设置中的“临时活动”。支持多个活动独立保存，各自以活动名称显示在关注列表分组栏。
- “更新名单”重新解析当前活动的来源，预览新增和移除的主播，确认后只替换该活动名单，不覆盖其他活动；“刷新状态”仅检测现有主播是否开播。
- 活动主播恢复与原关注列表相同的卡片布局、平台图标、头像、分类和房间号，仅不显示收藏爱心；读取失败仍明确标记状态未知。
- 自动迁移旧的单份临时列表并保留原始数据备份。活动删除、名单更新、改名与后台刷新并发时不会写回已删除名单或覆盖其他活动。
- 通过 19 项自动化测试及隔离浏览器交互测试。本次仍基于 3.x，不修改已封存的 4.x。

## 发布前第 1 次开发迭代 · 2026-10-21

### 新增

- 在分组标签栏增加独立的“临时关注”，为活动期间查看主播开播状态提供入口，不必逐个关注。
- 支持活动页解析、直播间链接列表，以及本机 txt / JSON / HTML 链接文件；先预览勾选，再确认替换，一次最多 300 个直播间。
- 优先读取斗鱼官方活动配置；对普通页面链接提取明确提示可能不完整。实测两个用户提供的活动页，分别提取 86 个、32 个与配置逐项一致的房间号，人数随活动实际内容变化。
- 支持斗鱼、虎牙和 B 站单房间公开状态读取；临时页支持直播中优先、只看正在直播、搜索、平台筛选、手动刷新和清空。

### 数据隔离与可靠性

- 临时列表仅保存在本机扩展存储，不混入正式关注、收藏、平台关注操作、桌面通知、直播记录或备份。
- 解析失败不覆盖原列表；替换或清空后，正在运行的旧刷新不能写回旧数据。并发检查合并，网络错误显示“状态未知”，视频轮播不计作直播。
- 新增斗鱼活动配置域名的读取权限；不新增脚本注入、Cookie 或本机程序权限，不自动打开平台页面。
- 基于 3.3.2 开发，不涉及已封存的 4.x 或抖音。

## 3.3.0 · 开发过程汇总

### 新功能

- 支持哔哩哔哩、斗鱼、虎牙三个平台的关注主播状态检查与开播提醒；移除 Twitch 平台功能。
- 增加平台诊断：查看平台读取状态、主播数量、最近检查时间和授权失效原因；可分别启用平台，并从列表或诊断页重新授权。
- 增加主播级提醒覆盖：未单独设置时沿用全局默认；可为单个主播单独开启或关闭，覆盖全局默认和分组提醒规则。
- 增加收藏分组管理、分组提醒开关、主播别名管理和主播列表拖动排序。
- 增加主播最近开播记录页面，记录由扩展检测到的开播状态变化。
- 增加封面模式：在“正在直播”列表中切换为封面卡片，默认仍使用原列表；卡片展示封面、头像、用户名、直播标题和收藏按钮。
- 增加快捷键说明页面及主页快捷键：`/` 聚焦搜索、`Esc` 清空搜索、`R` 刷新、`1`/`2`/`3` 切换列表、`?` 打开说明。
- 增加设置 JSON 导入导出和手动 WebDAV 上传/恢复；WebDAV 支持单独填写目录，目录留空时使用服务器映射的根路径。

### 界面与交互调整

- 为三个平台设计风格统一的平台图标，并使用各平台主题色标记开播状态；收藏标记由星形改为主题绿色爱心。
- 优化封面卡片的网格密度、封面显示区域和底部模糊信息条，减少信息条对封面的遮挡；可随时切回原样。
- 将收藏分组新增入口改为紧凑的“+”按钮，并使用弹窗管理分组。
- 将别名操作反馈改为自动消失的小提示，避免提示文字长期占据页面。
- 调整免打扰时间与提醒选项的布局；弹窗打开后自动聚焦对应输入框。
- 将“直播记录”和“快捷键”纳入统一导航，并让导航栏保持悬浮。

### 问题修复与可靠性改进

- 修复主播管理列表拖动排序不起作用的问题。
- 修复搜索框失焦后按 `Esc` 无法清空搜索的问题；输入控件和输入法组合输入期间避免误触快捷键。
- 修复平台授权提示的展示与关闭体验：未启用的平台不再要求授权或持续提醒，授权提示可单独关闭，仍保留重新授权入口。
- 修复页面滚动条出现时内容宽度变化造成的横向偏移，统一预留滚动条空间。
- 调整直播封面预览的位置，尽量避免预览框被页面边缘裁切。
- 改进 WebDAV 地址、目录和错误提示，使用通用服务器地址示例，明确 WebDAV 是手动备份/恢复，不是自动双向同步；备份不包含平台登录凭据或 WebDAV 账号配置。

## 说明

- 直播封面来自平台提供的静态封面图，不是直播视频流或录屏。
- 开播记录的开始时间是扩展首次检测到主播开播的时间，不一定等于平台实际开播时间。
- WebDAV 操作由用户手动触发；导入或恢复备份会覆盖相应设置。
